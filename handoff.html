A clearer path to your next chapter.

Nextrole is a responsive job portal prototype for discovering opportunities, understanding a role, and completing a focused application.

Explore the prototypeDownload Figma generatorView LinkedIn presentation

One connected candidate journey

  1. Search by role, company, or skill. Combine category, location, and experience filters.
  2. Open a job to review the description, responsibilities, company, benefits, and application steps.
  3. Apply using the three-step form: your details, experience and resume, then review.
  4. Use the labeled sample resume or select a PDF/DOCX up to 5 MB. Review, confirm, and submit the demo.
  5. Return to saved jobs or continue a draft in My applications.

All job openings and companies are sample content. Applications create local demo confirmations. Nothing is sent to an employer, and files are never uploaded.

Desktop clarity. Mobile flexibility.

Browser checks pass at 1440, 1024, 768, 390, and 360 px. Mobile uses collapsible filters, a navigation menu, stacked form fields, and a persistent apply action on job details.

Create the editable Figma design

  1. Extract the full project or the Figma generator ZIP.
  2. Open a Design file in the Figma desktop app.
  3. Choose Plugins → Development → Import plugin from manifest.
  4. Select figma-plugin/manifest.json and run Nextrole — Responsive Job Portal.
  5. Open Present and choose the desktop or mobile search-to-application flow.

The generator creates 21 editable screens, 5 component sets, Auto Layout, vertical scrolling, and 250 ms Smart Animate transitions. Buttons, checkboxes, bookmarks, and inputs include variant interactions.

The generator passes compilation and structural mock checks, but has not been run inside native Figma. A Figma account file is not included. Figma uses prepared example states; the browser implements actual typing, filters, drafts, and file selection.
